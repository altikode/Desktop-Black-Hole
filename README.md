🌌 Desktop Black Hole

A lightweight, interactive desktop widget built with Python and PyQt5. It replaces the default Windows Recycle Bin with an animated black hole that swallows files dropped into it and moves them directly to your system trash.

Everything is rendered programmatically using PyQt's drawing engine—no external assets or heavy engines required.
